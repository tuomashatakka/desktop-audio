# Feature: # Plan: UI Fixes + Frontend Data API + IPC and Web FS Adapters

This plan covers two ship-able batches: a set of focused UI fixes (Part A) and the data-source split (Part B). CSS-first throughout.

## Part A — UI Fixes
- A.1. Player vertical-stack layout at narrow widths (CSS-only)
- A.2. Stable bottom-player title container (CSS-only)
- A.3. Waveform fills full width + higher resolution
- A.4. Library table: padded scroll container, draggable + resizable + sortable headers
- A.5. Column visibility menu
- A.6. Settings page refactor + custom theme colours
- A.7. Row density button group (relaxed / normal / compact)
- A.8. Config caret + dropdown (column toggles + grouping)
- A.9. CSS-first principle
- A.10. Test plan for Part A

## Part B — Frontend Data API
- Extract data-access surface from Bridge into DataSource interface
- Ship IpcDataSource (wraps electronAPI)
- Ship WebFsDataSource (File System Access API)
- Wire both providers in renderer.tsx
- Migrate all consumers from useBridge() to useData()/useHost()
- Fix getAudioMetadata return-type regression
