## Done so far

### A.1 — Responsive player layouts ✓
- `src/app/styles/app.css` — `.player-bar` is now a CSS Grid with `container-type: inline-size`. Three `@container` breakpoints at 720 / 520 / 380 px progressively hide volume → time labels → wrap progress to a second row. Prev/play/next never disappear, just shrink.
- `src/app/styles/player.css` — full-screen `.player-view` stacks vertically below 480 px (was `flex-direction: row` with wrap). At 320 px the play/pause shrinks to 40 px.

### A.2 — Stable bottom-player title container ✓
- Title cell flexes inside a fixed-width grid track. `min-width: 0` + `text-overflow: ellipsis` keeps width invariant under track-title length. Both `.player-bar-title` and `.player-bar-artist` ellipsis cleanly.

### A.3 — Waveform fills container width + higher resolution ✓
- `src/app/styles/waveform-progress.css` — switched from `display: flex` with fixed `width: 5px` bars to `display: grid; grid-auto-flow: column; grid-auto-columns: 1fr`. Bars now stretch to fill any width.
- `src/app/contexts/AudioContext.tsx:297` — bumped the decoded bar count from 80 to 400.

### A.4 — Library track table foundations ✓
- `src/app/hooks/useColumnConfig.ts` — new hook persisting `{ key, label, width, visible, fixed }` columns to localStorage. API: `columns`, `visible`, `gridTemplate`, `toggleColumn`, `resizeColumn`, `reorderColumn`, `resetColumns`. Twelve column keys: `art, index, title, artist, album, year, genre, duration, format, size, trackNumber, path`.
- `src/app/hooks/useSortableTable.ts` — `SortKey` widened to all sortable columns; numeric keys (`duration`, `year`, `size`, `trackNumber`) use numeric compare.
- `src/app/contexts/UIContext.tsx` — added `density: 'compact' | 'normal' | 'relaxed'` and `grouping: 'none' | 'album' | 'artist' | 'path'`, both persisted to localStorage.
- `src/app/components/composite/TrackTable.tsx` — full rewrite:
  - Renders headers from `useColumnConfig.visible`. Each `<HeaderCell>` is `draggable`, has a `.col-resize-handle`, calls `toggleSort` on click, and exposes `onContextMenu` for the column-toggle menu.
  - `<ColumnMenu>` reuses the existing `Popover` atomic and calls `toggleColumn` per row.
  - Three render paths driven by `grouping`:
    - `'none'` — virtualized flat list (existing TanStack virtualizer pattern).
    - `'album'` — non-virtualized; each `.track-album-group` is a CSS Grid with the album art on the left spanning two grid rows; per-row art column is hidden inside groups.
    - `'artist' | 'path'` — non-virtualized; sticky `.track-group-header` above flat rows.
  - Density flows via `data-density` attribute and `--row-h`, `--row-pad-y`, `--row-clamp` custom properties.
- `src/app/styles/library.css` — track-table CSS rewritten end-to-end:
  - `.tracks-container` gets `padding: var(--sp-3) var(--sp-4)`.
  - `.track-table-wrap` has the density custom-property switch.
  - Grid template comes from the `--track-grid` CSS variable (mutated by JS via `style={{ '--track-grid': … }}`).
  - `.track-table-scroll` has `overflow-x: auto` for horizontal scroll when columns overflow.
  - Resize handle, drag affordance, sort indicator, group blocks, column-menu styles all included.
  - Relaxed density wraps the title cell to two physical lines (`.row-title` + `.row-subtitle`); compact and normal use `-webkit-line-clamp` to clamp overflow.
