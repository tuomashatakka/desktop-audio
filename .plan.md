# Feature: Update the public page to be more touch device friendly

## Overview
Make the public landing page (public/index.html, public/main.css, public/tokens.css) fully touch-friendly by improving tap targets, adding touch feedback, implementing swipe gestures, and optimizing scrolling behavior for touch devices.

## Phases

### Phase 1: Analyze requirements and existing codebase
- Review current touch-unfriendly issues in public/index.html and public/main.css
- Identify: nav-dots too small (10x10px), no swipe in lightbox, no touch feedback, hover-only states, viewport meta incomplete

### Phase 2: Implement core functionality

#### Task 2.1: Fix viewport meta tag and base touch styles
**Files**: `public/index.html`, `public/main.css`
- Add `viewport-fit=cover` to meta viewport
- Add `-webkit-tap-highlight-color: transparent` to disable iOS tap highlight
- Add `touch-action: manipulation` to buttons and interactive elements to remove 300ms delay
- Add `-webkit-overflow-scrolling: touch` to scroll-container for momentum scrolling

#### Task 2.2: Make nav-dots touch-friendly
**Files**: `public/main.css`
- Increase nav-dot size to minimum 44x44px hit area (Apple guideline)
- Keep visual size small but increase padding for hit area
- Add active/touch feedback state
- Position with larger right offset on mobile

#### Task 2.3: Improve CTA buttons and interactive elements for touch
**Files**: `public/main.css`
- Ensure CTA buttons have minimum 44px height
- Add `touch-action: manipulation` to prevent double-tap zoom
- Add active state with scale feedback for touch
- Increase gap in CTA group for mobile

#### Task 2.4: Add touch feedback for cards and interactive elements
**Files**: `public/main.css`
- Add `:active` state for screenshot-card, feature-card with scale/opacity feedback
- Add `touch-action: manipulation` to cards
- Ensure focus-visible works alongside touch (don't break keyboard nav)

#### Task 2.5: Implement swipe gestures for lightbox
**Files**: `public/index.html` (inside the `<script>` tag)
- Add touch event handlers (touchstart, touchmove, touchend) to lightbox
- Swipe left → next image
- Swipe right → previous image
- Swipe down or up → close lightbox
- Add threshold (50px) to distinguish tap from swipe
- Add inertia/swipe velocity detection

#### Task 2.6: Improve scrolling and overscroll behavior
**Files**: `public/main.css`
- Add `overscroll-behavior: none` to body to prevent pull-to-refresh during scroll-snap
- Add momentum scrolling for touch devices
- Ensure scroll-snap works well on touch (already has `scroll-snap-type: y mandatory`)

#### Task 2.7: Fix screenshot grid for touch devices
**Files**: `public/main.css`
- Increase minimum card size for touch targets
- Add proper spacing between cards for touch
- Ensure figcaption is readable on touch (no hover-only states)

#### Task 2.8: Add mobile-specific styles for touch
**Files**: `public/main.css`
- Enhance existing `@media (max-width: 768px)` media query
- Adjust nav-dots to bottom-center on mobile for easier thumb access
- Make lightbox controls larger on touch devices
- Adjust hero scroll hint (might interfere with touch scroll)

### Phase 3: Add tests
- Manual testing checklist for touch interactions
- Verify swipe gestures work in lightbox
- Verify tap targets meet 44px minimum

### Phase 4: Verify and document
- Run lint and typecheck
- Test with browser DevTools device mode
- Document touch improvements in CHANGELOG or relevant file
